# SAP AI Agents

Interactive customer presentation website for the Prowess SAP FICO agent concept.

## Run locally

Open `index.html` in a browser, or serve the repository directory:

```sh
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Files

- `index.html`: presentation content and page structure
- `style.css`: responsive styling, animation and reduced-motion support
- `app.js`: finance scenarios, architecture routes and autonomy controls

No build step or package installation is required. Google Fonts is optional; system fonts are used as fallback.

## Presentation scope

The finance records are illustrative. The website does not connect to SAP, execute transactions or collect credentials. Architecture, licensing, hosting and compliance content describes a proposed solution subject to customer and vendor validation.

The site includes three finance scenarios, two architecture views, five autonomy levels, hosting comparisons and proposed governance controls.
